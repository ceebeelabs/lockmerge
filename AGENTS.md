# AGENTS.md

Guidance for coding agents working in this repository. CLAUDE.md points here.

- **What this is:** a git merge driver that merges lockfiles by meaning. Read
  [README.md](README.md), then [docs/charter.md](docs/charter.md).
- **Phase:** research. The documents in `docs/` come before any code.
- **The rule:** combine what is provably unambiguous, refuse everything else,
  never guess. A wrong lockfile is the one unacceptable outcome.
- **Rules for every change:** [.daedalus/standing-rules.md](.daedalus/standing-rules.md).
- **How changes are reviewed:** [CONTRIBUTING.md](CONTRIBUTING.md), "Reviewing".
- Read the sections of documents your task points to, not whole documents.
